# ⚽ Pichangas Manager

Pichangas Manager es una aplicación web desarrollada con **Django** que simplifica la organización de partidos de fútbol casuales (“pichangas”).  
Centraliza la gestión de jugadores, pagos y equipos para evitar confusiones y mejorar la coordinación.

---

## 🌐 Demo en línea

👉 **Prueba la aplicación aquí:**  
https://pichanga-manager-demo.fly.dev/

> No requiere instalación local para probar sus funcionalidades principales.

---

## 🎯 Problema que resuelve

Organizar una pichanga suele implicar:
- ¿Quién confirmó?
- ¿Cuánto debe pagar cada uno?
- ¿Quién ya pagó?
- ¿Cómo armamos los equipos?

**Pichangas Manager** automatiza todo este proceso en una sola plataforma.

---

## 🚀 Funcionalidades Principales

- **Gestión de Partidos**
  - Crear encuentros con fecha, lugar y costo total.
- **División Automática de Gastos**
  - Cálculo dinámico del monto por jugador según los confirmados.
- **Control de Pagos**
  - El organizador puede marcar pagos en tiempo real.
- **Generador de Equipos**
  - Algoritmo de reparto aleatorio (Blanco vs. Color).
- **Usuarios e Invitados**
  - Soporte para jugadores registrados y “extranjeros” sin cuenta.
- **Autenticación Social**
  - Inicio de sesión rápido mediante Google OAuth 2.0.

---

## 🧠 Tipo de Proyecto

Proyecto **Fullstack**, orientado a:
- Gestión de comunidades.
- Automatización de procesos logísticos.
- Manejo de roles (organizador vs. jugador).
- Lógica financiera básica y persistencia de datos.

---

- **SQLite** – Base de datos
- **Google OAuth 2.0** – Autenticación
- **Docker** – Contenerización y despliegue
- **Fly.io** – Hosting de la demo
